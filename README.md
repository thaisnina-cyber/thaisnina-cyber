### 💰 Controlador de Finanças (Full Stack)
Aplicação **full stack** para organizar despesas e receitas.  
- **Frontend:** HTML, CSS e JavaScript  
- **Backend:** Python  

**História dos projetos:**  
Os dois projetos foram pensados para resolver problemas do meu dia a dia.  
Por exemplo, o **Controlador Financeiro** nasceu porque hoje faço esse controle em um caderno velho em casa e muitas vezes esqueço de anotar algum gasto ou de marcar que já paguei uma conta. Por isso tive a ideia de criar essa aplicação.  
No futuro quero também colocar **lembretes de pagamento de contas**, assim não esquecerei de pagar nada.

**Melhorias planejadas:**
- Integrar **Inteligência Artificial** para sugerir insights financeiros.
- Exportar dados para **planilha Excel** para melhor visualização.
- Implementar **Banco de Dados** para persistência das informações.
- Adicionar lembretes automáticos de pagamento de contas.
- Criar um espaço para **armazenar comprovantes de pagamento**, vinculados diretamente às contas registradas (ex.: paguei a conta de água → anexar comprovante junto).
